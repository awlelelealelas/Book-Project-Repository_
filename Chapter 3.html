3.1 Concept of Software

Software is a collection of programs and instructions that tells a computer what to do. It helps users perform different tasks and allows the hardware components of a computer to work properly.

3.1.1 Definition of Software

Software is a set of programs, instructions, and related data that directs a computer to perform specific tasks. Unlike hardware, software cannot be physically touched.

3.1.2 Categories of Software

  • System Software - Software that controls and manages computer hardware and provides a platform for other software to run. Examples include operating systems and device drivers.
  • Utility Software - Software designed to maintain, protect, and improve the performance of a computer. Examples include antivirus programs, backup tools, and disk cleanup utilities.
  • Application Software - Software developed to help users perform specific tasks such as writing documents, editing photos, playing games, or preparing presentations.
  • Web-Based Software - Software that runs through a web browser and usually does not require installation on the user's computer. Examples include online email, web-based editors, and online learning platforms.
  • Mobile Apps - Software applications designed mainly for mobile devices such as smartphones and tablets. They can be used for communication, entertainment, education, banking, and many other purposes.

3.2 Concept of Operating System

An operating system is system software that manages computer hardware and software resources. It provides an interface between the user and the computer and allows other programs to run.

3.2.1 Introduction to Operating System

An Operating System (OS) is the main system software of a computer. It controls the basic operations of the computer and provides an environment in which application programs can work. Examples include Windows, Linux, macOS, Android, and iOS.

3.2.2 Role of Operating System

The operating system acts as a link between the user, application software, and computer hardware. It manages system resources and makes it easier for users to operate the computer.

3.2.3 Functions of an Operating System

  • Process Management - Manages running programs and allocates CPU time to them.
  • Memory Management - Allocates and manages the computer's memory for different programs.
  • File Management - Organizes, stores, retrieves, and manages files and folders.
  • Device Management - Controls hardware devices such as keyboards, printers, and storage devices.
  • Security Management - Protects data and system resources using passwords, permissions, and other security features.
  • User Interface - Provides a way for users to interact with the computer through graphical or command-based interfaces.

3.2.4 Operating System Terminology

  • Multiprogramming - A technique in which multiple programs are kept in memory at the same time so the CPU can work on different programs efficiently.
  • Multitasking - The ability of an operating system to run multiple tasks or programs seemingly at the same time.
  • Multiprocessing - The use of two or more processors or CPU cores to execute multiple processes and improve performance.
  • Distributed Operating System - An operating system that manages multiple connected computers and makes them work together as a single system.

3.3 Windows Operating System

Windows is a popular graphical operating system developed by Microsoft. It provides an easy-to-use interface for managing files, programs, devices, and other computer resources.

3.3.1 Introduction to GUI Based Operating System and its Features

A GUI (Graphical User Interface) based operating system allows users to interact with a computer using graphical elements such as windows, icons, menus, buttons, and a pointer instead of typing commands for every operation.

Features of GUI:

  • Icons - Small graphical symbols representing files, folders, applications, or commands.
  • Windows - Rectangular areas where applications and documents are displayed.
  • Menus - Lists of commands or options available to the user.
  • Pointer - Used to select and interact with objects on the screen.
  • Desktop - The main screen where icons, shortcuts, and other elements are displayed.

3.3.2 Working in Desktop Application and Window Environment

A desktop application is a program designed to run directly on a computer. In Windows, applications usually appear inside windows that can be opened, closed, minimized, maximized, and resized.

The desktop provides access to applications, files, folders, shortcuts, the Start menu, and the taskbar.

3.3.3 Manage Files and Folders with File Explorer

File Explorer is a Windows tool used to view and manage files and folders. Users can create, open, copy, move, rename, delete, and search for files and folders using File Explorer.

3.3.4 Customize the Start Screen and Desktop

Windows allows users to customize the appearance and arrangement of the Start menu and desktop. Users can change wallpapers, themes, icons, taskbar settings, and other display options according to their preferences.

3.3.5 Installing and Removing Devices

Windows can detect and configure many hardware devices automatically using device drivers. Devices such as printers, keyboards, mice, and external storage can be installed and removed through Windows settings or Device Manager.

3.3.6 Manage Passwords and Privacy Levels

Windows provides security features for protecting user accounts and personal information. Users can create and change passwords, manage account permissions, and control privacy settings such as access to location, camera, microphone, and personal data.

3.3.7 Use of Control Panel, System Tools and Accessories

Control Panel provides tools for changing and managing various Windows settings such as hardware, programs, user accounts, and system options.

System Tools are tools used to maintain, manage, and troubleshoot the computer. Examples include Disk Cleanup, Task Manager, and System Information.

Accessories are built-in applications that help users perform common tasks. Examples include Notepad, Paint, Calculator, and Snipping Tool.

3.4 Open Sources and Mobile Operating System

Open-source operating systems provide access to their source code, allowing users and developers to study, modify, and distribute the software according to its license. Mobile operating systems are designed specifically to manage smartphones and tablets.

3.4.1 Concept of Open Source Operating System

An open-source operating system is an operating system whose source code is publicly available. Users and developers can study, modify, improve, and distribute the software according to its license.

3.4.2 Introduction to Linux and UNIX

Linux is a popular open-source operating system based on UNIX-like principles. It is widely used in personal computers, servers, supercomputers, and embedded systems.

UNIX is a powerful multi-user and multitasking operating system originally developed at Bell Labs. It has influenced many modern operating systems, including Linux and other UNIX-based systems.

3.4.3 Linux Distributions

A Linux distribution is a complete operating system built around the Linux kernel along with system tools, software packages, and a package manager. Different distributions are designed for different types of users and purposes.

  • Ubuntu - A popular and user-friendly Linux distribution.
  • Fedora - A modern distribution often used for development and testing new technologies.
  • Debian - A stable distribution known for its large software repository.
  • Linux Mint - A beginner-friendly distribution with a familiar desktop environment.

3.4.4 Concept of Mobile Operating System

A mobile operating system is system software designed to manage mobile devices such as smartphones and tablets. It manages hardware, applications, memory, connectivity, security, and the user interface of the device.

3.4.5 Types of Mobile Operating System

  • Android - A widely used mobile operating system developed by Google and based on the Linux kernel.
  • iOS - Apple's mobile operating system designed for devices such as the iPhone.
  • HarmonyOS - An operating system developed by Huawei for various types of smart devices.
  • KaiOS - A lightweight mobile operating system designed mainly for feature phones with smart features.
