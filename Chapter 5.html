5.1 Programming Concept

Programming is the process of writing a set of instructions that tells a computer how to perform a particular task. These instructions are written using programming languages and are converted into a form that the computer can understand and execute.

5.1.1 Introduction to Programming Languages

A programming language is a formal language used to write instructions for a computer. It provides rules and symbols that programmers use to create programs and solve different problems.

Programming languages can be classified into different levels depending on how closely they are related to machine language. Examples include C, C++, Java, Python, and JavaScript.

5.1.2 Low Level, High Level and 4 GL Programming Languages

  • Low-Level Language - A programming language that is closely related to the hardware and machine language of a computer. It provides greater control over hardware but is more difficult for humans to understand. Machine language and assembly language are examples.
  • High-Level Language - A programming language that uses words and symbols that are easier for humans to understand. It makes programming easier and more portable between different computers. Examples include C, C++, Java, and Python.
  • Fourth Generation Language (4GL) - A high-level language designed to make programming easier by using commands that are closer to natural human language. It is commonly used for database management, report generation, and application development.

5.1.3 Compiler, Interpreter and Assembler

  • Compiler - A program that translates the entire high-level language program into machine code before execution. It reports errors after analyzing the program. C and C++ commonly use compilers.
  • Interpreter - A program that translates and executes a high-level program line by line. It stops when it encounters an error. Python and JavaScript commonly use interpreters.
  • Assembler - A program that converts assembly language instructions into machine language so that the computer can execute them.

5.1.4 Syntax, Semantic and Runtime Errors

  • Syntax Error - An error caused by violating the grammatical rules of a programming language, such as missing a semicolon or using incorrect syntax.
  • Semantic Error - An error that occurs when the statements are syntactically correct but do not perform the intended operation or meaning.
  • Runtime Error - An error that occurs while a program is running. It may happen because of problems such as division by zero or accessing invalid data.

5.1.5 Control Structures: Sequence, Selection and Iteration

Control structures determine the order in which instructions in a program are executed. They help a program make decisions and repeat tasks when necessary.

  • Sequence - Statements are executed one after another in the order in which they appear.
  • Selection - A program chooses between different statements or paths based on a condition. Examples include if, if-else, and switch.
  • Iteration - A set of statements is repeatedly executed as long as a particular condition is satisfied. Examples include while, do-while, and for loops.

5.1.6 Program Design Tools – Algorithm, Flowchart and Pseudocode

  • Algorithm - A step-by-step procedure used to solve a particular problem. It clearly describes the sequence of operations required to obtain a result.
  • Flowchart - A graphical representation of an algorithm. It uses standard symbols and arrows to show the flow of a program or process.
  • Pseudocode - A simple way of writing the steps of a program using ordinary language and programming-like statements without following the exact syntax of a programming language.

5.1.7 ASCII, BCD and Unicode

Binary - Binary is a number system that represents information using only 0 and 1. Computers use binary because their electronic circuits can represent two basic states.

BCD (Binary Coded Decimal) - BCD is a method of representing each decimal digit separately using four binary bits. For example, the decimal digit 5 is represented as 0101.

ASCII (American Standard Code for Information Interchange) - ASCII is a character encoding system used to represent letters, numbers, symbols, and control characters using numerical codes.

Unicode - Unicode is a character encoding standard that represents characters from many languages and writing systems around the world. It allows computers to handle a much larger range of characters than traditional ASCII.

5.2 C Programming Language

C is a general-purpose programming language developed by Dennis Ritchie at Bell Labs. It is widely used for system software, application development, embedded systems, and learning programming concepts.

5.2.1 Introduction and Features of C Language

C is a structured and general-purpose programming language. It provides features that allow programmers to write efficient and relatively fast programs.

  • Simple - C has a relatively small set of keywords and a straightforward syntax.
  • Structured - Programs can be divided into functions and logical sections.
  • Portable - C programs can be adapted to run on different types of computers with little modification.
  • Fast and Efficient - C provides efficient execution and allows direct interaction with computer memory.
  • Extensible - Programs can be extended by adding functions and libraries.

5.2.2 Structure of C Program

A C program generally consists of several parts such as preprocessor directives, the main function, variable declarations, statements, and other functions.

The main() function is the starting point of execution in a C program. Statements inside the main function are executed when the program runs.

#include <stdio.h>

int main()
{
    printf("Hello World");
    return 0;
}

5.2.3 C Preprocessor and Header Files

The C preprocessor processes special instructions before the actual compilation of a program. Preprocessor directives usually begin with the # symbol.

Header files contain predefined functions, declarations, and other information that can be included in a C program. For example, stdio.h contains functions such as printf() and scanf().

5.2.4 Character Set Used in C

The C character set consists of the characters that can be used to write C programs. It includes letters, digits, special symbols, white spaces, and other characters supported by the language.

  • Letters - A-Z and a-z
  • Digits - 0-9
  • Special Symbols - +, -, *, /, %, =, &, #, etc.
  • White Spaces - Space, tab, and newline characters.

5.2.5 Use of Comments

Comments are explanatory notes written inside a program. They are ignored by the compiler and are used to make the program easier to understand and maintain.

C supports single-line comments using // and multi-line comments using /* */.

5.2.6 Identifiers, Keywords and Tokens

  • Identifier - A name given to program elements such as variables, functions, and arrays. Examples include total, marks, and studentName.
  • Keyword - A reserved word that has a predefined meaning in C and cannot normally be used as an identifier. Examples include int, float, if, else, and return.
  • Token - The smallest individual unit of a C program. Keywords, identifiers, constants, operators, and special symbols are examples of tokens.

5.2.7 Basic Data Types in C

Data types specify the type of data that a variable can store. Common basic data types in C include:

  • int - Stores integer numbers.
  • float - Stores decimal numbers with single precision.
  • double - Stores decimal numbers with greater precision than float.
  • char - Stores a single character.
  • void - Represents the absence of a value or data type.

5.2.8 Constants and Variables

Constant - A value that does not change during program execution. Examples include 10, 3.14, and 'A'.

Variable - A named memory location used to store a value that can change during program execution.

int age = 16;
float price = 25.50;

5.2.9 Type Specifier

Type specifiers are used to specify the type of data that a variable, function, or expression represents. Common type specifiers in C include int, char, float, double, and void.

5.2.10 Simple and Compound Statements

Simple Statement - A single instruction that usually ends with a semicolon. For example, x = 10; is a simple statement.

Compound Statement - A group of statements enclosed within curly braces { }. It is commonly used with functions, loops, and decision-making statements.

5.2.11 Operators and Expressions

Operators are symbols used to perform operations on values and variables. An expression is a combination of variables, constants, and operators that produces a value.

  • Arithmetic Operators - Used for mathematical operations such as +, -, *, /, and %.
  • Relational Operators - Used to compare values, such as >, <, ==, !=, >=, and <=.
  • Logical Operators - Used to perform logical operations: && (AND), || (OR), and ! (NOT).
  • Assignment Operators - Used to assign values to variables, such as =, +=, -=, *=, and /=.
  • Unary Operators - Operate on a single operand, such as ++, --, and !.
  • Conditional Operator - A ternary operator written as ? : and used to choose between two values based on a condition.

5.2.12 Input/Output (I/O) Functions

Input/output functions are used to receive data from the user and display results on the screen.

  • printf() - Used to display output on the screen.
  • scanf() - Used to receive formatted input from the user.
  • getchar() - Used to read a single character.
  • putchar() - Used to display a single character.

5.2.13 Selection Control Statement: Decisions

Selection statements allow a program to make decisions and execute different statements depending on whether a condition is true or false.

  • if - Executes a statement when a specified condition is true.
  • if-else - Executes one block when the condition is true and another block when it is false.
  • if-else-if - Tests multiple conditions one after another.
  • Nested if - An if statement placed inside another if or else statement.
  • switch - Selects one block of statements from multiple choices based on the value of an expression.

5.2.14 Iteration Control Statement: Looping

Looping statements are used to execute a block of statements repeatedly until a particular condition is satisfied.

  • while - Repeats a block of statements while the condition remains true.
  • do-while - Executes the block at least once and then repeats it while the condition is true.
  • for - Used when the initialization, condition, and update of a loop can be written together.
  • Nested Loop - A loop placed inside another loop. It is commonly used for working with tables and matrices.

5.2.15 Array: Definition and Types

An array is a collection of elements of the same data type stored under a single name. Each element is accessed using an index.

  • One-Dimensional Array - Stores elements in a single row or list. For example, marks of several students can be stored in a 1D array.
  • Two-Dimensional Array - Stores elements in rows and columns. It is commonly used to represent tables and matrices.

Matrix Addition - Two matrices of the same order can be added by adding their corresponding elements.

Matrix Subtraction - Two matrices of the same order can be subtracted by subtracting each element of the second matrix from the corresponding element of the first matrix.

5.2.16 String and String Functions

A string is a sequence of characters stored in a character array and terminated by a special null character \0. Strings are commonly used to store names, words, sentences, and other text.

C provides several functions for performing operations on strings. Many of these functions are available through the string.h header file.

  • strlen() - Finds the length of a string.
  • strcat() - Joins or concatenates two strings.
  • strcmp() - Compares two strings.
  • strrev() - Reverses a string in implementations that provide this function.
  • strcpy() - Copies one string into another.
  • strlwr() - Converts a string into lowercase in implementations that provide this function.
  • strupr() - Converts a string into uppercase in implementations that provide this function.
