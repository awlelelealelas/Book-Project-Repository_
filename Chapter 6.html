6.1 Introduction: Web Development

Web development is the process of creating and maintaining websites and web applications. It involves designing web pages, writing code, managing content, and making websites available through the internet. HTML, CSS, and JavaScript are commonly used in web development.

6.2 Web Browsers and Search Engines

Web Browser - A web browser is software used to access and view websites on the internet. It interprets web pages and displays their content to users. Examples include Google Chrome, Mozilla Firefox, Microsoft Edge, and Safari.

Search Engine - A search engine is an online service used to find information on the internet. It searches its database for pages related to the user's query and displays relevant results. Examples include Google, Bing, and Yahoo.

6.3 Overview of Various Internet and Web Technologies

Internet and web technologies are tools and standards used to communicate, share information, and create websites and online services. Some important technologies include HTML for webpage structure, CSS for styling, JavaScript for interactivity, HTTP/HTTPS for communication, and URLs for identifying web resources.

6.4 Content Management System (CMS)

A Content Management System (CMS) is software that allows users to create, edit, organize, and publish website content without requiring extensive programming knowledge. It is commonly used for blogs, school websites, news sites, and business websites.

Examples of CMS include WordPress, Joomla, and Drupal.

6.4 HTML: The Language of the Web

HTML (HyperText Markup Language) is the standard markup language used to create and structure web pages. It uses tags and elements to define headings, paragraphs, images, links, tables, forms, and other webpage content.

6.4.1 Objectives

The main objective of HTML is to provide a standard way of structuring and presenting content on web pages. It helps browsers understand how different parts of a webpage should be displayed.

6.4.2 Structure of HTML

An HTML document normally contains the HTML, HEAD, and BODY sections. The HEAD contains information about the webpage, while the BODY contains the content displayed on the webpage.

<html>
<head>
<title>My Page</title>
</head>
<body>
Content goes here
</body>
</html>

6.4.3 Publishing and Hosting

Publishing a website means making its web pages available to users on the internet. Web hosting is a service that provides storage and resources for website files so that they can be accessed online.

6.4.4 HTML Tags vs. Attributes

HTML Tags are special keywords enclosed in angle brackets that define the structure or meaning of webpage content. Examples include <p>, <h1>, and <table>.

Attributes provide additional information about an HTML element. They are normally written inside the opening tag. For example, align can specify the alignment of an element.

6.4.5 Basic Tags of HTML

  • <HTML> - Defines the beginning and end of an HTML document.
  • <HEAD> - Contains information about the webpage that is not normally displayed as page content.
  • <TITLE> - Defines the title displayed on the browser tab.
  • <BODY> - Contains the main visible content of the webpage.

The BODY section can be used to set properties such as text color, background color, and background image. Older HTML versions also supported background sound.

6.4.6 Heading Tag (H1 to H6) and ALIGN Attribute

Heading tags are used to create headings of different sizes. HTML provides six heading levels from <H1> to <H6>, where H1 is the largest and most important heading and H6 is the smallest.

The ALIGN attribute was traditionally used to align content such as headings to the left, center, right, or justify positions.

6.4.7 FONT Tag and Attributes

The <FONT> tag was used in older HTML to change the appearance of text. Its attributes included SIZE, COLOR, and other formatting options. Font size could be specified from 1 to 7.

  • BASEFONT - Used to specify the default font size.
  • SMALL - Displays text smaller than normal.
  • BIG - Displays text larger than normal.
  • COLOR - Specifies the color of text.

6.4.8 Paragraph Formatting (P)

The <P> tag is used to create a paragraph in HTML. It automatically separates the paragraph from surrounding content and makes text easier to read.

6.4.9 Break Line BR

The <BR> tag is used to insert a line break within text. It moves the following content to the next line without creating a new paragraph.

6.4.10 Comment in HTML

HTML comments are notes written inside the code that are ignored by the browser. They are useful for explaining code or leaving notes for developers.

<!-- This is an HTML comment -->

6.4.11 Formatting Text

  • <B> - Makes text bold.
  • <I> - Makes text italic.
  • <U> - Underlines text.
  • <MARK> - Highlights text.
  • <SUP> - Displays text as superscript.
  • <SUB> - Displays text as subscript.
  • <EM> - Gives emphasis to text, usually displayed in italic.
  • <BLOCKQUOTE> - Displays a section as a quotation.
  • <PRE> - Displays preformatted text while preserving spaces and line breaks.

6.4.12 Ordered List - OL

An ordered list displays items in a particular sequence, usually using numbers or letters. The <OL> tag creates the list and <LI> defines each item.

The TYPE attribute can use values such as 1, I, A, or a. The START attribute specifies the starting number or letter, while VALUE can specify the value of an individual list item.

6.4.13 Unordered List - UL

An unordered list displays items using bullet symbols rather than a sequence. The <UL> tag creates the list and <LI> defines each item.

Common bullet types include disc, circle, and square. The <DL>, <DT>, and <DD> tags are used for description lists, terms, and their descriptions.

6.4.14 ADDRESS Tag and Creating Links

The <ADDRESS> tag is used to provide contact or author information related to a webpage.

Links allow users to move from one webpage or resource to another. The <A> (Anchor) tag is used to create hyperlinks in HTML.

  • Link to another HTML document - Connects the current webpage to another HTML page.
  • Link within the same document - Moves the user to another section of the current webpage.
  • Link to another place in another document - Opens a specific section of another webpage.
  • Hyperlink - A clickable text or object that takes the user to another location or resource.

6.4.15 Tables

HTML tables are used to arrange information in rows and columns. The <TABLE> tag creates a table, <TR> creates a row, <TH> creates a heading cell, and <TD> creates a normal data cell.

6.4.16 Forms

HTML forms are used to collect information from users. Forms can contain different input elements such as textboxes, radio buttons, checkboxes, text areas, and buttons.

  • Textbox - Allows the user to enter short text.
  • Radio Button - Allows the user to select one option from a group.
  • Checkbox - Allows the user to select one or more options.
  • Text Area - Allows the user to enter larger amounts of text.
  • Button - Performs an action such as submitting or resetting a form.

6.4.17 Introduction to HTML5 Elements

HTML5 introduced several elements for handling multimedia and other modern web content without requiring additional plugins.

  • <AUDIO> - Used to add audio content to a webpage.
  • <VIDEO> - Used to display video content.
  • <SOURCE> - Specifies different media sources.
  • <TRACK> - Provides text tracks such as subtitles or captions.
  • <EMBED> - Embeds external content into a webpage.

6.4.18 HTML5 Graphics using Canvas and SVG

Canvas provides a drawing area where graphics can be created using scripts such as JavaScript. It can be used for drawings, animations, games, and charts.

SVG (Scalable Vector Graphics) is an XML-based format used to create two-dimensional vector graphics. SVG graphics can be resized without losing their quality.

6.4.19 Concept of Domain Name and Web Hosting

Domain Name is the human-readable address used to access a website on the internet, such as example.com. It is easier to remember than a numerical IP address.

Web Hosting is a service that stores website files on a server and makes them accessible through the internet.

6.5 Cascading Style Sheets

Cascading Style Sheets (CSS) is a stylesheet language used to control the appearance and layout of HTML webpages. It can change colors, fonts, spacing, borders, sizes, and the overall design of a webpage.

6.5.1 Introduction to Cascading Style Sheet (CSS)

CSS separates the presentation of a webpage from its HTML structure. It allows developers to apply consistent styles to multiple elements and webpages, making websites easier to design and maintain.

6.5.2 Inline CSS

Inline CSS is written directly inside an HTML element using the style attribute. It is mainly used when a style needs to be applied to a specific individual element.

<p style="color: blue;">Hello</p>

6.5.3 Embedded CSS

Embedded CSS is written inside the <style> tag, usually within the <head> section of an HTML document. It is useful when styles are intended for a single webpage.

6.5.4 External CSS

External CSS is written in a separate .css file and linked to an HTML document. It is useful for applying the same styles to multiple webpages and makes website maintenance easier.
